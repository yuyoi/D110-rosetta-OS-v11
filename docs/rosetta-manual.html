1 The Rosetta family

Rosetta is a set of upgrades that turn the D-110 into a more playable, more personal instrument. They work on their own or together.

Rosetta OSPerformance features in the D-110's own firmware: arpeggiator with groove, step sequencer, chords, unison, mono and glide, mod matrix with synced LFO, wave sequencing and the Lab sound experiments. This manual covers Rosetta OS.
Rosetta ROMYour own samples in place of the factory PCM waves. Rosetta Studio prepares the wave data and names, so recorded sounds play from the D-110 like its built-in waves.
Rosetta BakerA small tool that adds Rosetta OS to the owner's own firmware dumps and prepares the files for the upgrade. Nothing from Roland is distributed.

2 Before you start

Installation noteRosetta OS v12 is a two-chip upgrade (OS chip and control chip). The OS chip has been the same since v8; moving to a newer revision only replaces the control chip. Revision v12 has passed bench simulation; v9 is the last revision confirmed on a unit.

On power-up the display shows the Rosetta banner for a moment, then the normal Play screen. All stock D-110 functions work as before. Rosetta settings are kept in memory when the power is off.

3 Quick screen & CC knobs

Hold Enter and press Edit. The Quick screen edits the sound of the current part directly, all four partials at once.

MIDI control on each part's channel: CC74 cutoff, CC71 resonance, CC73 attack, CC72 release.

The filter acts on synthesizer partials (square and saw). PCM partials have no filter; use level, wave and Lab functions on them instead.

Plain labels. The stock edit pages use plain words: OS, Pitch, Vibr., Flt, Flt Env, Amp, Amp Env.

5 Wave

Chord >

One key plays a chord: Off, Octave, Fifth, 5th+Oct, Major, Minor, Sus4, Major7, Minor7, Dom7, Minor9, Dim, Learned, Scale, Scale 7.

  • Chord Learn — press Bank ▲, play up to five notes on the chord part, release. Chord switches to Learned. Bank ▼ cancels.
  • Scale Key C–B and Scale Type (Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harmonic Minor, Melodic Minor): with Scale, each key plays the triad of its scale degree; Scale 7 plays the seventh chord.
  • Chord Part chooses the part.

Seq: the recorded pattern

Up to 32 steps of notes, rests and ties, kept in memory. Set Arp Mode to Seq to play it; the key you hold transposes it. A demo pattern is stored from the start. Seq Length sets 1–32 steps.

Seq Record, on the Arp Mode page:

  • Bank ▲ — Step recording. Each key is one step. Number ▲ enters a rest, Number ▼ a tie.
  • Bank ▲ again before the first key — Live recording. The first key starts the clock and the display changes to Rec; keys land on the nearest step and held keys become ties.
  • Bank ▼ — stop. The steps so far become the pattern.
Seq Record Step 05/32
Seq Record Done 16/32

The counter moves as you play, and Done shows when recording has stopped, either by Bank ▼ or because all 32 steps are filled.

9 Lab

Lab > reaches into the LA sound chip directly. Results range from subtle to completely new sounds, and some settings fall silent. Lab is switched On or Off as a whole; Lab Part chooses the part.

ParameterValuesWhat it does
Lab Reso HighOff, 0–7Upper resonance bits. 7 gives far stronger resonance than the stock maximum
Lab Reso LowOff, 0–31Lower resonance bits, including values never used by the factory sounds
Lab Ctrl XOR0–255Alters synth partials. With Reso High 7, values such as 8 turn notes into airy transient sounds; every value is different
Lab PCM XOR0–255The same for PCM partials
Lab PCM Pos0–255Shifts where a PCM partial reads its sample: other waves, other regions of memory

10 Info & troubleshooting

Info Mem oooo P01 v12

Info tests the memory Rosetta uses (o = good, X = fault), and shows the current part and the revision.

SymptomRemedy
Banner reads “D-110 ROSETTA”, menu has no effectThe control chip upgrade is not detected. Have the installation checked.
Notes keep soundingExit the menu and select the patch again, or send All Notes Off.
Filter has no effectThe partial is PCM; PCM partials have no filter.
A Lab sound went silentSet the Lab values back to 0 / Off, or switch Lab Off.
Settings changed after an updateA new revision may reset settings to their defaults. Set them again.
Internal tempo slightly offUse MIDI clock; synced timing is exact.
